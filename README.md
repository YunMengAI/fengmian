# ComfyUI 爆款封面 LLM 提示词插件

这个插件只保留一个节点：

`YM-爆款封面`

它会调用 RunningHub 的 LLM 能力，根据必填的封面标题，以及可选的图片、主题和补充要求，生成一段可以继续接到生图节点使用的中文封面创意指令。

新版以封面标题为设计核心，不会把标题机械扩写成冗长构图清单。用户只填写标题时，LLM 也会自行判断题材、受众和视觉概念，再让生图模型完成一张真正经过设计的完整封面。

`封面标题`是唯一必填的创作内容。图片、封面风格、主题关键词和自定义要求都可以留空；没有参考图和补充文案时，节点会直接围绕标题策划完整封面。

## 节点输入

- `model`：RunningHub LLM 模型下拉框，优先从 `https://llm.runninghub.ai/v1/models` 获取
- `封面风格`：可选的审美方向，默认不指定，由模型根据标题和参考图自行设计
- `主题关键词`：封面围绕的主题，例如 AI提示词、穿搭教程、产品种草、工具介绍等
- `封面标题`：必填，希望直接出现在封面上的标题
- `加载图像`：可选，接 ComfyUI 自带的 Load Image 节点
- `api_key`：可选，RunningHub 平台环境通常不需要填写
- `api_baseurl`：默认 `https://llm.runninghub.cn/v1`
- `自定义要求`：可选，用于写自定义风格、标题位置、画面比例、保留元素、不要额外文字等要求
- `temperature`
- `max_tokens`

## 封面风格

当前内置风格：

- `不指定（根据标题自动设计）`
- `小红书干净高级风`
- `强冲击爆款标题风`
- `科技感教程封面风`
- `商业海报风`
- `杂志大片风`
- `可爱手账风`
- `电商产品种草风`
- `真实生活方式风`
- `自定义`

这些风格只是轻量审美参考，不是固定模板，也不会强制加入某套配色、贴纸、字效或构图。希望模型自由发挥时，保持默认的 `不指定（根据标题自动设计）` 即可。

如果选择 `自定义`，请在 `自定义要求` 里填写具体风格描述，例如：

```text
韩系杂志感，白色背景，人物偏右，标题放左侧，干净高级
```

每次切换封面风格后需要重新运行工作流。节点会使用新的执行标识强制调用 LLM，并作为输出节点参与执行，避免下游文案展示节点继续读取旧缓存。后台日志里的 `cover_style` 可用于确认本次实际发送的风格。

## 节点输出

- `封面提示词`

这里的输出是 LLM 根据图片或文字需求生成的简洁封面创意指令，可以继续接到后面的图像生成节点。

## 图片识别

接入图片时，节点会把图片转换成 JPEG base64，并以 OpenAI 兼容的多模态格式发送：

```text
text + image_url
```

运行时后台会打印类似信息：

```json
{
  "has_image": true,
  "content_type": "multimodal",
  "image_size": [1080, 1922]
}
```

如果看到 `has_image: true`，说明节点已经收到图片并随请求发送给模型。

## 内容安全

系统提示词会要求 LLM 使用自然、尊重、非性化的描述，但不再对“透明、服装、身体”等词做机械替换，避免破坏正常产品材质、人物穿搭和参考图内容。最终是否通过安全审查仍取决于后续生图模型和平台策略。

## API Key

在 RunningHub 托管的 ComfyUI 环境中，如果平台已经自动注入共享 Key，通常不需要手动填写 `api_key`。

普通本地 ComfyUI 直接调用 RunningHub 接口时需要鉴权，请在节点里的 `api_key` 输入框填写，或者设置环境变量：

```bash
RH_API_KEY=你的RunningHubKey
```

## RunningHub LLM

节点默认调用 RunningHub 官方 LLM OpenAI 兼容接口：

```text
https://llm.runninghub.cn/v1/chat/completions
```

模型下拉框会优先从 RunningHub 模型接口获取：

```text
https://llm.runninghub.ai/v1/models
```

如果当前运行环境临时拉不到模型接口，节点会显示备用模型列表。

## 在 ComfyUI 里搜什么

搜索：

```text
爆款封面
```

或：

```text
YM-爆款封面
```

## 系统提示词维护

系统提示词在：

```text
system_prompt.txt
```

以后要调整爆款封面规则、识图策略、标题生成规则、输出格式，优先改这个文件。

## 安装

把整个仓库文件夹放进 ComfyUI 的：

```text
custom_nodes/
```

然后重启 ComfyUI。
